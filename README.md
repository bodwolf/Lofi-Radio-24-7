## ✨ Overview

Renner Radio is built as a frontend-only web app using **HTML, CSS, Vanilla JavaScript, Firebase, and the YouTube IFrame API**.

The project is designed to feel like a futuristic radio control room: dark, calm, neon, responsive, and interactive.

🔗 **Live Demo:**
https://rennerlabs.github.io/Lofi-Radio-24-7/

---

## 🚀 Features

| Area                 | Details                                                                                                |
| -------------------- | ------------------------------------------------------------------------------------------------------ |
| 🎧 Radio Playback    | YouTube-powered station playback with station switching, random station, volume, and player controls.  |
| 🛰️ Station Grid     | Main station list with clean category dividers and admin-managed stations.                             |
| 🔥 Realtime Sync     | Firebase Realtime Database support for chat, profiles, Community FM, admin stations, and settings.     |
| 💬 Anonymous Chat    | Visitor chat with custom English display names and realtime updates.                                   |
| 📡 Community FM      | Temporary user-created radio channels with nested YouTube tracks.                                      |
| 🛠️ Studio Panel     | Private station manager for importing, editing, disabling, removing, and sorting stations.             |
| 🌃 Visual Mood       | Animated background hooks, tuning glitch, static sound option, comfort mode, and cyberpunk UI styling. |
| 📱 Responsive Layout | Desktop dashboard experience with mobile-friendly panels and internal scrolling.                       |

## 🔥 Firebase

Real Firebase config values are not committed.

Use this file as a local template:

```txt
firebase-config.example.js -> firebase-config.js
```

Firebase paths used by the app:

* `/adminStations`
* `/temporaryStations`
* `/chatMessages`
* `/userProfiles`
* `/siteSettings`
